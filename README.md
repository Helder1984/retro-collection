# Retro Collection

Projeto de cards colecionáveis inspirado nos brindes promocionais dos anos 80 e 90.

---

## Sobre

Retro Collection é uma série de coleções fan-made focada em personagens clássicos dos videogames.

Cada coleção utiliza uma identidade visual própria e segue um padrão consistente de produção.
