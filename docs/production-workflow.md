# Production Workflow

## Objective

Document the standard creation process used for Retro Collection cards.

---

# Stage 1 — Planning

## Theme Selection

Define the collection theme.

Examples:

- Super Mario Bros
- Sonic the Hedgehog
- Mega Man
- Street Fighter
- Donkey Kong Country

---

## Character Research

Create a complete list of characters that will be included in the collection.

---

## Collection Size Definition

Examples:

- 32 cards
- 64 cards
- 100 cards

---

# Stage 2 — Preparation

## Research

Search for official character artwork or the closest possible representation of the original source material.

---

## Image Selection

Choose the image that best represents the character.

### Criteria

- Strong visual readability
- Removable background
- Faithful appearance to the original game

---

# Stage 3 — Production

## Character Reconstruction

Recreate the character in high resolution using the original in-game images as reference, reimagining it in the Retro Collection style.

### Goals

- High image quality
- Clean edges
- Accurate colors
- Sharp details

---

# Stage 4 — Card Assembly

## Open Template

Use the official Retro Collection template.

---

## Insert Character

Position the character or item artwork.

---

## Apply Background

Insert a background that matches the color palette of the character or item.

---

## Apply Card Number

Insert the collection card number and the number frame designed for the selected background.

---

## Aply logo

Insert the logo designed for the selected background.

---

## Apply Character Name

Insert the official character name with the effects designed for the selected background.

---

# Stage 5 — Review

Verify:

- Spelling
- Character name
- Card number
- Alignment
- Borders
- Visual quality

---

# Stage 6 — Export

Export:

- PNG

---

# Stage 7 — Printing

Prepare the print sheet.

---

# Stage 8 — Archiving

Save:

- Editable source file
- Final PNG
- Printed version
